## 4. Review and Merge Evidence

For each contribution, we record:

1. The corresponding YouTrack task ID and link.
2. The Git branch used to implement the task.
3. The commit hash and commit message.
4. The GitHub pull request link.
5. The name of the team member who reviewed the changes.
6. The review outcome and merge status.

A pull request is recorded as merged only after its status has been confirmed on GitHub. We do not claim ownership of work without verifiable evidence.

## 5. Contribution Verification Rules

- Each task should have a clearly identifiable branch and relevant commits.
- Commit messages should reference the corresponding YouTrack task.
- Pull requests should explain the changes and how they were checked.
- Team members should review each other's changes before merging.
- The contribution log should be updated when tasks are reviewed and merged.
- Dates, commit hashes, pull request URLs, reviewers, and statuses must be verified using GitHub and YouTrack.
- Contributions should reflect the work actually completed by each team member.

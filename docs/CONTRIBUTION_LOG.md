# Contribution log

Each student's contribution is traced through four independent sources:

1. **GitHub commits**: each student commits from their own account; email addresses must be verified on GitHub. Authorship is never overridden.
2. **Pull requests**: every change enters `main` via a PR naming the YouTrack task (`DIP-<n>`).
3. **Reviews**: each PR is reviewed and approved by the other student.
4. **YouTrack tasks**: tasks have assignees, states and due dates; commits and PRs reference `DIP-<n>`.
